# 校内信息服务智能问答台

面向校内师生的信息化处信息问答工具。作品以“知识库检索 + 标准答案生成 + 来源追溯 + 反馈闭环 + 知识维护”为主线，帮助用户快速查询账号、网络、正版软件、VPN、邮箱、报修与安全类问题。

## 作品基本信息

- 作品名称：校内信息服务智能问答台
- 作品类型：可运行的软件工具
- 使用场景：校园信息化处服务咨询、服务大厅导办、常见问题自助查询
- 面向对象：校内学生、教职工、访客服务人员
- 核心价值：减少重复咨询，提高服务响应效率，让问答结果有来源、有责任岗、有反馈

## 功能介绍

- 问答检索：输入自然语言问题后，系统从本地知识库中匹配最相关条目并生成标准答复。
- 分类浏览：按账号与安全、网络服务、软件服务、协同办公、服务大厅等分类查看。
- 来源追溯：每条回答展示来源、更新时间、责任岗位，便于后续审核和维护。
- 快捷问题：内置校园网、VPN、正版软件、统一身份认证、报修等高频入口。
- 反馈闭环：记录“有帮助”和“需人工跟进”，用于评估知识库质量。
- 知识维护：支持在浏览器本机新增临时知识草稿，便于演示后台维护流程。

## 运行环境

- Node.js：`>=22.13.0`
- 主要框架：Next.js、React、Vinext、Vite
- 数据存储：当前版本使用内置本地知识库和浏览器 localStorage，无需外部数据库

## 使用方法

```bash
pnpm install
pnpm run dev
```

打开本地预览地址后即可使用。开发服务器默认会输出类似：

```text
http://localhost:3000/
```

构建验证：

```bash
pnpm run build
pnpm test
```

## 原创与合规承诺

本项目源码和页面内容由参赛者围绕校园信息化服务场景自主设计开发。项目不包含破解软件、激活工具或规避授权机制，不采集真实个人敏感信息。示例链接和服务条目用于演示，可在正式提交前替换为学校审核后的真实材料。
