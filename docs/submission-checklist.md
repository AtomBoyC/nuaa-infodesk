- [ ] 作者确定本作品的使用许可，并把相应许可正文放入材料。目前仓库没有 LICENSE 文件，不能以第三方依赖的许可证代替作品许可。
- [ ] 第三方开源依赖与许可证清单。主程序直接依赖 Streamlit 1.62.0；本机安装元数据标注 Apache-2.0。打包时还应核对实际安装的传递依赖、随软件分发的许可文件；React 版本如一并提交，也需要单独列出其依赖。
- [ ] 使用比赛正式模板填写并签署《原创权属及版权合规承诺书》。README 中的说明不能代替签名文件。
- [ ] 演示材料：建议录制 2 至 3 分钟视频，展示搜索、候选切换、分类浏览、草稿发布、来源和反馈。
- [ ] 对 Word 历史版本、默认示例和官网摘录中的办理口径、联系人、链接、日期进行业务审核，避免把历史说明直接当作现行规定。
- [ ] 在实际部署服务器按 README 安装并运行一次。GitHub Actions 已验证 Python 3.10/3.12 和 Docker 容器，服务器网络、域名和 HTTPS 仍需现场验收。

## 建议演示顺序

1. 打开首页，搜索“校园网连不上怎么办”，展示独立结果页和相关候选。
2. 切换候选，展示标准答复、办理步骤和来源记录同步更新。
3. 搜索“今天中午吃什么”，展示无相关知识时的处理。
4. 进入知识目录筛选，再切换到常用服务和最近会话。
5. 保存一条演示草稿，审核发布后再查询；避免把演示草稿留入正式提交库。
6. 导出知识库并展示 `python check_knowledge.py` 的结果。

## 部署范围

可使用 Docker Compose 部署到单台远程服务器，知识维护已支持密码文件登录，并提供可选的域名 HTTPS 代理。镜像构建、容器健康和数据持久化已通过 GitHub Actions 检查；域名和服务器网络仍需在目标环境验收。“需人工跟进”目前只记录反馈，尚未连接真实工单分派或通知系统。浏览器会话历史也不等于持久化工单。

私有 GitHub 源码仓库地址是源码查看入口，不是已部署的 Streamlit 访问链接。参赛时可按要求提供安装与运行方法，或部署后的实际访问地址。
